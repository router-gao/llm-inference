# NVIDIA认证与后续学习路线

状态：新增内容设计，待官方核验。此页帮助目标读者选择后续学习方向，不是考试大纲、报考承诺或题库。当前没有已核实的在开放考试清单。

## 1. 先区分认证与学习证明

- 专业认证：通常有明确考试、能力范围与资格/有效期规则，须核实具体项目。
- 培训或课程完成证明：完成课程或实验后取得，不能仅因有证书就等同专业认证。
- 学习路径：课程组合或推荐资源，不一定对应考试。

NVIDIA培训、课程证书与认证考试分别展示。相关产品能力或职业熟练度也不能只由一张证书推断。
