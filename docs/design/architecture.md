# 整体静态站点架构 v0.2

状态：待 review，M0 设计提案；本文件不是已实现架构。体验以[交互设计](experience.md)为依据，阶段与责任以[任务板](../project/tasks.md)为准。本轮不编写应用代码、安装框架或部署。

## 1. 架构目标与技术选择

网站在浏览器内运行中文模拟教学，不需要后端、GPU、模型/酒店 API、账户或密钥。内容、资源快照和示例结果随静态文件分发，不向第三方发送学习输入。建议原生 HTML/CSS/JavaScript ES modules，无框架和运行时 CDN；通过静态 HTTP 服务运行，不把直接打开 file:// 作为支持方式。静态部署可迁移，第一版无需构建步骤；测试工具可作为开发依赖另行决定。

选择依据是交互以确定性状态和结构化内容为主，规模可控，模块边界比框架更重要。若后续多语言、复杂路由或内容量明显增加，在决策记录中评估框架与内容构建工具，不在 M0 预先增加依赖。

## 2. 模块边界

| 模块 | 负责 | 不负责 |
| --- | --- | --- |
| 页面壳与导航 | 页面地图、路线、标题、深链接和错误入口 | 生成技术内容 |
| 内容目录与校验 | 场景、术语、模型/GPU 配置、来源与版本 | 执行数据内的任意代码 |
| 场景状态机 | 步骤、分支、确认、前后复位与播放 | 真实工具执行或随机业务状态 |
| 流程渲染 | 四视角节点/连线、有序文本与图例 | 私自推进时间线 |
| 说明与资源面板 | 输入输出、假设、资源快照、工程展开 | 将估算当实测 |
| 容量公式 | 单位转换、权重/KV/余量分项与限制 | 预测真实 QPS、TTFT 或采购保证 |
| 并发/调度模拟 | 确定性队列与请求轨迹、策略示例 | 冒充真实推理引擎调度 |
| 来源/术语呈现 | 首次解释、检索、证据状态与日期 | 自动声称官方支持 |

建议文件结构为 index.html、assets/、src/{navigation,state,player,flow,detail,capacity,simulation}.js、content/{scenarios,glossary,models,gpus,sources}/。页面可采用静态页面加共享模块或 hash 导航；若用 hash，需保留浏览器前后退、分享链接和刷新恢复。部署子路径作为链接评审项，不硬编码站点根目录。

## 3. 内容 schema 与来源状态

以下为交接字段说明，不是实现代码。内容必须可校验、稳定 ID 可交叉引用，教学文字以文本渲染，禁止直接注入未经处理的 HTML。

- **Lesson**：id、版本、标题、目标、读者路线标签、阶段、先修链接、scenarioIds、术语与来源引用、编辑/审校状态。
- **Scenario**：id、版本、输入字段、默认值、假设、initialStepId、步骤图、分支定义、模拟标志、自测。
- **Step**：id、标题、允许转换及条件、四视角 views、完整 snapshot、确认需求、sources；每个 View 包含执行者、解释、输入、动作、输出、等待对象、节点与边、工程细节。
- **Snapshot**：requestId、工具状态、订单状态、确认记录、队列、GPU 活动、资源项与时间线；资源项包含 value/unit/status/assumptions，status 区分示意、估算、实测和未建模。
- **Model/GPU configuration**：id、名称、参数与单位、适用公式类型、配置来源、平台/机型/版本约束；缺失字段显式未知。MoE 不以激活参数替代需驻留权重。
- **Source**：id、标题、发布者、URL、版本/发布日期、访问或核验日期、所支持的具体断言、核验负责人、状态与备注。

来源状态统一为“待核验 / 已核验 / 访问受阻 / 已失效”；内容状态为“草案 / 待审校 / 已审校”。二者独立：有 URL 不代表核验完成，文案审校通过也不代表参数已核验。官方规格支持参数与兼容性，实测报告支持限定条件下的性能，教学假设只支持示意。UCS 支持清单必须绑定具体服务器、GPU、配置/软件版本与官方依据；访问受阻时展示候选与待核验提示，不输出已支持结论。

内容校验至少检查 ID 唯一、四视角存在、引用可解、转换目标存在、单位合法、确认成功路径约束、未知状态明确、来源断言范围。发布阶段不得把待核验性能数字显示为事实。

## 4. 确定性步骤、分支与状态

统一酒店八步为接收意图、整理约束、应用检查、查库存与价格、比较候选、用户确认、应用执行预订、告知结果。面向读者的短标签可用“搜索/推荐/执行/回执”，其稳定步骤 ID 依次为 hotel.intent、hotel.constraints、hotel.validation、hotel.search、hotel.recommendation、hotel.confirmation、hotel.booking、hotel.receipt；标题调整不更换 ID。Lesson.id 是课程导航接口，Scenario.id 是播放器接口，Step.id 是课程内过程定位接口，URL 与跨模块链接不得用中文标题充当 ID。routeId 只选择理解沟通/方案工程的推荐路线，perspective 只选择 user/agent/model/infra 运行视角，两者互不映射。其他场景使用相同引擎。UI 状态包括 scenarioId、scenarioVersion、stepId、branchId、perspective、playing、detailsOpen、inputs、confirmation；分支所需的历史记录明确保留，返回选择点时清除不再适用的确认与结果。

状态更新通过有限事件：选择场景、选择视角、下一步、上一步、跳步、选分支、确认、改变参数、重置、播放/暂停。转换是纯粹、可重放的规则；渲染只消费结果。资源读取完整快照或由纯函数从固定轨迹计算，不采用点击次数累加。模拟没有随机网络结果；若以后引入随机，必须固定种子并显示假设。

下一步按当前分支走；上一步按已走路径返回。任意跳步只进入合法教学预览，不能制造未获得的确认、订单成功或其他副作用。第六步默认暂停，明确确认后第七步才允许成功预订分支；改变日期、价格或房型使确认失效。超时结果为未知，进入查单路径，不能重复提交后自动成功。切视角保持请求与路径，重置恢复全部默认值并停止播放。后台标签页暂停，页面销毁清理定时器。

分享 URL 仅保存非敏感教学状态，如页面/场景/步骤/视角；非法 ID 回到安全默认并提示。M1 不持久化学习输入。后续可选 localStorage 需版本迁移、清除入口和隐私说明。

## 5. 公式与资源模块

M1 资源是概念快照，M2 才交付参数计算器。计算核心接受结构化参数，返回分项字节数、GiB 展示、假设、警告和不适用原因，与界面解耦。统一以 bytes 为内部单位，展示明确 GB/GiB；不得混用参数数量单位与显存单位。

基础近似：权重字节数 ≈ 驻留参数数 × 每参数字节数；量化配置另计元数据及运行时格式，不能默认精确压缩比。KV 字节数 ≈ 2 × 层数 × KV heads × head dimension × 已缓存 token 总数 × KV dtype 字节数。使用 KV heads 而非强制等于 query heads；多请求用各请求 token 总和，简单均长近似须说明。总量包含权重、KV、临时运行/激活及预留余量，不把 Q 当持续增长的缓存。

公式版本、适用模型、并行/副本假设必须与结果一起显示。稠密/GQA/MQA/MoE、量化、分片和 KV 复制可能改变分项；不支持的配置返回“需专门模型”，不输出伪精确结果。显存可容纳不等于吞吐或延迟达标；GPU 张数不简单等于总量除卡容量后取整，需考虑可分片性、每卡驻留、互联与余量。M2提供单卡及完整模型副本的每卡账本，对未实现的分片方式显示不适用或待核验；M3在核验并行规则后扩展TP/PP等模型分片的每卡估算。

输入检查正整数/范围、dtype、缺失配置、超出容量及非数值；计算测试使用独立手算算例和单位/单调性检查，避免仅复述实现。GPU/UCS 对照连接已核验规格，不自动推出性能倍数。

## 6. 测试、部署与演进

M0：检查文档、术语、八步与阶段一致性，schema/公式与未决问题评审。M1：状态转换单元验证、成功/澄清/失败/确认边界、浏览器交互、键盘/辅助技术、窄屏与减少动效。M2：公式与边界、RAG 数据衔接、并发释放/取消与确定性回放；M3：拓扑/通信与多模型隔离语义。所有阶段区分设计验收与真实功能测试证据，详见[质量规范](../quality/validation.md)。

静态部署平台与公开范围尚未确定；GitHub Pages 可作为候选，在发布决策后验证子路径、刷新、链接和缓存。版本发布包含内容版本、核验日期、已知限制和可回退静态产物。不要把密钥或真实客户配置加入静态文件。未来若接真实模型或酒店工具，另立需求和后端信任边界，不复用浏览器模拟确认作为业务授权。

主要风险：类比误导、四视角状态错位、异常跳步绕过确认、资源数字伪精确、官方规格失效、拓扑小屏不可读、动效影响理解。对应控制为类比边界说明、统一状态机、转换约束、单位与假设、来源生命周期、文本流程替代和减少动效。待 review 决策：原生模块方案、URL 恢复范围、代表模型/UCS 机型、公式支持范围及发布平台；不阻塞当前文档评审。
