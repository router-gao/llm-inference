# 文生视频独立首页：先被作品吸引，再探索制作

状态：正式需求REQ-20的设计初稿，待视觉原型review。用户明确“有自己的首页、必须炫酷、吸引普通人”。本稿是方向与验收，尚未实现视觉或生成视频。

## 目标与独立性

文生视频拥有独立可分享入口与导航，建议未来路径video/。不只是主站中的一张卡或工程课程章节。主站有入口，视频首页可回到主学习站；共享品牌/术语体系，但采用面向大众的作品驱动表达。

受众是普通访客，首屏不需要AI、GPU或IT知识。“炫酷”靠精选作品、节奏、构图与可控互动表达，不等于大量粒子、闪烁或不可读文字。

## 视觉与内容方向

建议深色电影感画布、鲜明但克制的强调色、大面积精选视频/分镜、短文案与明显操作按钮。先做可review视觉原型，再确定最终颜色与排版。

1. **首屏作品舞台**：同一创意的提示词/分镜与成片呼应，候选标题“把脑海里的画面，变成一段故事”。主操作“看看它怎么诞生”，次操作“探索作品”。清晰标记“预生成样例/教学模拟”，保留署名/来源。
2. **一眼看懂的变化**：可点击切换风格、地区或镜头版本，显示对应固定授权样例；参数变化不伪称实时调用模型。对照不预设Seedance必然优于本地。
3. **作品展廊**：场景卡如旅游短片、产品故事、剧情预演，点击看短片、brief和分镜。没有已授权素材时展示原型占位，不盗用电影/演员或伪造来源。
4. **两条生成路径**：用“云端创作 / 自己的设备”面向大众表达，展开才显示Seedance、具体本地模型、资源与条件。入口不能暗示当前已经有真实API服务。
5. **创作接力**：灵感→脚本→分镜→生成→修订→成片的短互动，强调人工创意/审核与后期，不暗示一条提示自动替代整个制作过程。
6. **按兴趣继续**：看作品、理解制作、探索本地部署与云本地协作；产业/中东改编候选仍待RES-03讨论，不因首页设计自动批准商业专题。

## 动效、媒体与性能

视频自动播放仅在浏览器和用户偏好允许时静音尝试，失败显示海报与播放按钮；不自动播放声音。提供暂停、字幕/文本描述；减少动效时用静态海报。避免闪烁，文字独立于画面变化，键盘可达。

移动端优先海报与点击播放；控制首屏媒体大小，提供合理编码、懒加载和加载反馈。作品丰富不能造成初次访问长时间空白。实际媒体预算及性能阈值在样例选择后测量约定，不先承诺秒数。

## 交付与验收

M2交付独立视频首页、授权作品展示、可点击制作过程与路径入口；M3扩展本地/云协作、资源/运维入口。普通用户首页不默认展开参数/机架图，也不把工程入口隐藏。

验收：独立URL可分享，主站/视频导航互通；普通访客无需术语即可理解并完成首次互动；影片来源/生成状态正确；视觉原型由用户review；真实媒体在手机/桌面可播放或正确降级，无声自动播放和控制可用；键盘/字幕/减少动效及加载性能有实测。吸引力需普通访客反馈，不能只由团队声称“炫酷”。

真实在线生成、账户、付费与视频业务后台不由本需求自动引入；目前仍是静态展示与教学。Seedance真实能力/地区/API与本地模型配置按REQ-18/RES-03核验。
